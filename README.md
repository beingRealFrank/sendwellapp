# Sendwell: free Shopify email template designer

Design a branded Shopify order confirmation, shipping confirmation or refund email in your browser, with a live preview, and copy a ready-to-paste Liquid template.

**Use it:** https://beingrealfrank.github.io/sendwellapp/

Templates are plain Shopify Liquid on Shopify's notification variables; nothing loads from outside Shopify. Problems or a missing email type? Open an issue.

This repository is the published site; it is built from a private source repo.
