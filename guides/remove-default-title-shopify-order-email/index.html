How to remove "Default Title" from Shopify order emails

If a product has no variants (no size, color or other option), Shopify still gives it one hidden variant named Default Title. A notification template that prints the variant name for every line therefore shows customers things like "Canvas Tote · Default Title".

The fix

Open the email under Settings › Notifications, click Edit code, find where the variant title is printed and wrap it:

{% if line.variant_title != blank and line.variant_title != 'Default Title' %}
  <span>{{ line.variant_title }}</span>
{% endif %}

Some templates use line.variant.title instead of line.variant_title; apply the same check to whichever one your code prints. In the refund email the line is one level down, so it's refund_line.line_item.variant_title.

Don't forget the separator

If the template prints a separator before the variant (·, /, - or ×), move it inside the same if. Otherwise "Default Title" disappears but a lonely "·" stays behind.

Check every email

The same code is usually copied into the order confirmation, shipping confirmation, shipping update and refund emails, and each needs the fix. Test with an order that has one product with variants and one without.
