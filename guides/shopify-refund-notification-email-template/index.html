Shopify refund notification email: variables and a branded template

The refund notification is the email customers get when you refund an order and leave Send a notification to the customer checked. It is easy to forget, so many stores still send Shopify's plain default after branding the order confirmation.

Where it lives

Settings › Notifications › Customer notifications › Refund (listed under order exceptions), then Edit code. Like every notification it has a subject and an HTML body in Liquid. Save a copy of the body before you change it.

The variables it gets

{{ amount | money }}          the amount refunded this time (not the order total)
{{ order_name }}             #1042
{{ customer.first_name }}
{{ order_status_url }}
{% for refund_line in refund_line_items %}
  {{ refund_line.line_item.title }}
  {{ refund_line.quantity }}       how many of that item were refunded
  {{ refund_line.line_item.final_price | times: refund_line.quantity | money }}
{% endfor %}

Two things trip people up. First, refund_line_items holds only what was refunded in this refund, so a partial refund lists only those items; use it instead of line_items, which is the whole order. Second, the item details sit one level down under .line_item.

Refunds without items

A refund of shipping only, or a goodwill amount, has an empty refund_line_items. Wrap the item table so it doesn't render empty:

{% if refund_line_items.size > 0 %}
  <!-- the item table -->
{% endif %}
<p>We refunded {{ amount | money }} to your original payment method.</p>

What to say

Customers open a refund email to check three things: how much, for what, and when it will arrive. Put the amount in the heading, list the items, and say that banks usually take a few business days to show it. A link to {{ order_status_url }} saves you a support email.

Testing without a real customer

Send test email uses sample data. For a real check, place a test order with your own email (Bogus Gateway or a draft order marked paid), refund one item with the notification on, and look at the email in your inbox.

The same mistakes that break the order confirmation apply here: double quotes inside style attributes, flexbox layouts and "Default Title" on products without variants. See customizing the order confirmation email.
