Switching from a Shopify email template app to a pasted template

Shopify doesn't let apps edit your notification templates: there is no API for it. So every email template app works the same way underneath: it gives you Liquid code, and you (or a browser helper) paste it into Settings › Notifications. That has two useful consequences.

Uninstalling the app doesn't change your emails

The pasted code lives in your store, not in the app. If you uninstall, your emails keep sending exactly as they are. The only exception is a template that loads images or settings from the app's own servers; check the code for image links that aren't on cdn.shopify.com and replace them.

Before you switch

  1. For each email you customized (order confirmation, shipping confirmation, refund and any others), open Edit code and save a copy of the current body and subject.
  2. Note what you liked: logo size, colors, wording, extra sections such as a discount code or a review request.

Switch in a few minutes

  1. Open the free designer, set your brand color, font, logo link and wording, and check the preview for each email.
  2. Copy the template, open the same email in Shopify, select all of the code, paste and Save.
  3. Send yourself a test, then place or resend a real test order.

If anything looks wrong, paste your saved copy back or click Revert to default.

What to look for in any template

  • Plain Liquid on Shopify's own variables, so it keeps working if any outside service goes away.
  • Table-based layout with inline styles (Outlook ignores most modern CSS).
  • Handles products without variants (no "Default Title") and orders without a shipping address.
Skip the hand-editing. Design the email in your browser with a live preview and copy a ready-to-paste template: free, no install.
