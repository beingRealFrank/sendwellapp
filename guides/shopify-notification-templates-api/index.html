Can you edit Shopify notification templates through the API?

Short answer: no. As of November 2026 there is no Admin API endpoint, REST or GraphQL, that reads or writes the templates under Settings › Notifications. Developers have asked for one on Shopify's developer forum for years; staff have passed the requests on, and nothing has shipped.

Why not just script the admin?

The admin saves templates through an internal endpoint. Calling it from a script or a browser bot breaks Shopify's API Terms, which forbid bypassing API restrictions "including automating administrative functions of the Merchant Store Admin". Apps also may not ask merchants for their admin credentials. So every email template app ends with the same step: the merchant pastes the code and clicks Save.

What does work: templates that read shop metafields

Notification templates can read the store's own metafields, and the Admin API can write those with metafieldsSet. So you paste a template once that pulls its content from metafields, and after that the API changes what the email shows, without touching the template again.

<p>{{ shop.metafields.emails.order_intro }}</p>
<style>{{ shop.metafields.emails.css }}</style>

What we measured on a Basic plan store (November 2026):

  • Read metafields with the plain form, shop.metafields.ns.key. Adding .value renders nothing.
  • json metafields are parsed: read keys directly, like shop.metafields.ns.cfg.heading. Printing the whole object gives a Ruby-style hash.
  • Multi-line text metafields cap at 65,536 characters. A JSON metafield holding a 307,206-character HTML string was accepted and rendered in Shopify's preview.
  • Changing only the metafields changed the real delivered email. No Shopify Plus needed.
  • Use your own namespace (we used a custom one throughout).

Keep the Liquid in the template

Put order variables in the template and plain placeholders in the metafield, then swap them with replace:

{{ shop.metafields.emails.cfg.heading | replace: '[[first_name]]', customer.first_name }}

That way the metafield is just text and markup, and every order still fills in its own name, items and links.

One catch with styles

Shopify moves CSS inline when it sends the email. A double quote inside an inline style attribute, such as a font stack with "Times New Roman", ends the attribute early and the styles after it vanish. Use single quotes there.
