Change the font and center the Shopify order confirmation email

Shopify's branding settings change the logo and accent color, not the font or the layout. Both live in the template code: Settings › Notifications › Customer notifications › Order confirmation › Edit code. Save a copy of the body before you start.

Fonts that actually arrive

Gmail and Outlook ignore most custom web fonts, so a font loaded from Google Fonts may show in Apple Mail and fall back everywhere else. Pick a font stack that degrades well:

Georgia, 'Times New Roman', serif          classic
Arial, Helvetica, sans-serif               clean
'Trebuchet MS', Arial, sans-serif          friendly
Verdana, Geneva, sans-serif                wide, very readable

If you do use a web font, put it first and keep a stack like the ones above behind it.

Set it once, with single quotes

Shopify moves CSS inline when it sends the email, into style="…" attributes. A double quote inside a font name ends that attribute early and the styles after it disappear. So write font names with single quotes everywhere: in the <style> block and in inline styles.

<style>
  body, td, p, a, h1, h2 { font-family: Georgia, 'Times New Roman', serif; }
</style>

Setting it on td matters: some clients don't inherit the font from body into tables.

Center the email

margin: 0 auto on a div works in Gmail and Apple Mail but not in Outlook for Windows. Use a full-width table with a centered, fixed-width table inside:

<table role="presentation" width="100%" cellpadding="0" cellspacing="0"><tr>
  <td align="center">
    <table role="presentation" width="600" cellpadding="0" cellspacing="0" style="width:100%; max-width:600px">
      <tr><td style="padding:24px"> … your content … </td></tr>
    </table>
  </td>
</tr></table>

The 600px width with max-width keeps it readable on desktop and lets it shrink on phones.

Center the logo and the button

<td align="center">
  <img src="https://cdn.shopify.com/…/logo.png" width="160" alt="{{ shop.name }}" style="display:block; margin:0 auto; border:0">
</td>

Give the image a width attribute (Outlook ignores CSS widths on images) and display:block to avoid a gap under it. For a button, put the link in a centered cell: <td align="center"><a href="{{ order_status_url }}" style="display:inline-block; padding:12px 26px; background:#1f6f5c; color:#ffffff; text-decoration:none; border-radius:6px">View your order</a></td>.

Centering only the heading

Use text-align:center on the cell or heading, not the <center> tag, and leave the item list left-aligned: centered prices are hard to scan.
