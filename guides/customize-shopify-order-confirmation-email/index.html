How to customize the Shopify order confirmation email

Shopify sends the order confirmation email itself, from a Liquid template you can edit in your admin. There are two levels of change: the no-code branding settings, and the template code.

1. Change logo and color without code

Go to Settings › Notifications, then Customize email templates (the branding section). There you can upload a logo, set its width and pick an accent color. These apply to every notification, but the layout and wording stay Shopify's default.

2. Edit the template itself

  1. Go to Settings › Notifications › Customer notifications and open Order confirmation.
  2. Click Edit code. You get two fields: the email subject and the HTML body, both written in Liquid.
  3. Copy the whole body somewhere safe before changing anything. (Revert to default also brings Shopify's version back.)
  4. Edit, click Save, then use Send test email to see it in a real inbox.

3. The variables you will use

Inside notification templates the order isn't referenced as order.; its fields are top-level variables:

{{ order_name }}            #1042
{{ customer.first_name }}   Maya
{{ created_at | date: '%B %-d, %Y' }}
{{ subtotal_price | money }}  {{ shipping_price | money }}  {{ tax_price | money }}  {{ total_price | money }}
{{ order_status_url }}       the customer's order status page
{% for line in line_items %}
  {{ line.title }} {{ line.variant_title }} × {{ line.quantity }} {{ line.final_line_price | money }}
  {{ line.image | img_url: 'compact_cropped' }}
{% endfor %}
{{ shipping_address.name }}, {{ shipping_address.address1 }}, {{ shipping_address.city }}

Prices are in cents, so always pass them through money.

4. Mistakes that break the email

  • Double quotes inside style attributes. Shopify moves your CSS inline when it sends the email, so a font stack like font-family: Georgia, "Times New Roman" inside style="…" ends the attribute early and the rest of the styling disappears. Use single quotes inside styles.
  • "Default Title" showing up. Products without variants have the variant title Default Title. Hide it: {% if line.variant_title != 'Default Title' %}.
  • Stray separators. If you print {{ line.variant_title }} × and the item has no variant, customers see a lonely "×". Build the separator only when there is a variant.
  • Layout with divs and flexbox. Outlook ignores most modern CSS. Use tables with inline widths for anything side by side.
  • Images from your laptop. Logos must be public HTTPS links: upload under Content › Files and copy the link.

5. Test with a real order

Send test email uses sample data. To see real products and an address, create a test order (a draft order marked as paid works) and open Resend from the order's timeline.
